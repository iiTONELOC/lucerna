# Scío de San Miguel

Spanish Catholic Bible of Felipe Scío de San Miguel, 73 books, verses numbered as the Vulgate. Public domain.

Source: Latin Prayer JSON API, https://latinprayer.org/spanish/index.json, one request every 4 seconds, downloaded 2026-11-01 and scanned with ClamAV before use. Verse text is kept exactly as served; only the file format is changed to USFM.
