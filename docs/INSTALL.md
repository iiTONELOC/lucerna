# Add Lucerna to your device

Lucerna works in a browser. Add it to your device and it opens like any other application.

[Back to the README](../README.md)

## iPhone

**Safari**

1. Open Lucerna in Safari.
2. Tap the More button at the bottom right.

   <img src="../src/assets/install/iphone-1-more.avif" alt="Safari on iPhone with the More button marked at the bottom right" width="320" />

3. Tap Share.

   <img src="../src/assets/install/iphone-2-share.avif" alt="The Safari menu on iPhone with Share marked" width="320" />

4. Tap More at the end of the row of actions.

   <img src="../src/assets/install/iphone-3-more.avif" alt="The iPhone share panel with the More button marked in the row of actions" width="320" />

5. Tap Add to Home Screen.

   <img src="../src/assets/install/iphone-4-add.avif" alt="The expanded iPhone share panel with Add to Home Screen marked" width="320" />

6. Keep Open as Web App switched on, then tap Add.

   <img src="../src/assets/install/iphone-5-confirm.avif" alt="The Add to Home Screen panel on iPhone with the Add button marked" width="320" />

## iPad

   <img src="../src/assets/install/ipad-1-share.avif" alt="Safari on iPad with the Share button marked at the top right" width="320" />

3. Tap More at the end of the row of actions.

   <img src="../src/assets/install/ipad-2-more.avif" alt="The iPad share panel with the More button marked in the row of actions" width="320" />

4. Tap Add to Home Screen.

   <img src="../src/assets/install/ipad-3-add.avif" alt="The expanded iPad share panel with Add to Home Screen marked" width="320" />

5. Keep Open as Web App switched on, then tap Add.

   <img src="../src/assets/install/ipad-4-confirm.avif" alt="The Add to Home Screen panel on iPad with the Add button marked" width="320" />

## Mac

**Safari**

You can also choose File, then Add to Dock. This needs macOS Sonoma or later.

1. Open Lucerna in Safari.
2. Click the Share button, then click Add to Dock.

   <img src="../src/assets/install/mac-1-add-to-dock.avif" alt="The Safari share menu on a Mac with Add to Dock marked" width="320" />

3. Type a name, then click Add.

   <img src="../src/assets/install/mac-2-confirm.avif" alt="The Add to Dock panel on a Mac with the Add button marked" width="320" />

## Android

**Chrome, Brave, Edge, Opera, Samsung Internet**

Choose Install, not Create shortcut. A shortcut opens in the browser instead.

1. Open Lucerna in Chrome.
2. Tap the menu button at the top right.

   <img src="../src/assets/install/android-1-menu.avif" alt="Chrome on Android with the menu button marked at the top right" width="320" />

3. Tap Add to Home screen.

   <img src="../src/assets/install/android-2-add.avif" alt="The Chrome menu on Android with Add to Home screen marked" width="320" />

4. Tap Install.

   <img src="../src/assets/install/android-3-install.avif" alt="The Add to home screen panel on Android with Install marked" width="320" />

5. Tap Install again to confirm.

   <img src="../src/assets/install/android-4-confirm.avif" alt="The Install app panel on Android with the Install button marked" width="320" />

## Windows and Linux

**Chrome, Brave, Edge, Opera**

Chrome, Brave, Edge, and Opera work the same way on a Mac.

1. Open Lucerna in the browser.
2. Click the install icon at the right of the address bar.
3. Click Install.

## Firefox

**Firefox**

Firefox on the desktop cannot install web applications. Use Chrome, Brave, Edge, Opera, or Safari.

1. Open Lucerna in Firefox on an Android phone or tablet.
2. Tap the menu button.
3. Tap Install.
